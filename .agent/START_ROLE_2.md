## Как завершать каждый небольшой этап

Полезный запрос:

> Проверь мой текущий diff: соответствие контракту, отсутствие подставных показателей, двойные переходы, подписки старой сцены, очистку при возврате, паузу и лишние изменения. Исправь найденное в моей области, выполни относящиеся проверки, обнови мой статус и подготовь маленькую передачу участнику 1. Покажи, что проверить руками. Ничего не отправляй на GitHub и не меняй боевые файлы товарища молча.

После проверки можно поручить локальную фиксацию:

> Создай локальный коммит только с проверенными изменениями моего этапа, их .meta и моим статусом. Используй явный список путей, не добавляй всё подряд. Сохрани чужие незавершённые изменения, не выполняй принудительный reset и не отправляй историю внешним сервисам.

Из подтверждённого доступного Git-корня:

```powershell
git status --short
git diff
git diff --cached
```

Приёмка общей ветки и её передача происходят выбранным командой способом после просмотра товарищем. Pull или merge выполняются с учётом текущих локальных правок; «починить» рабочую копию их стиранием нельзя.
