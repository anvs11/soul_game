Проверка не назначает желаемое значение оружия напрямую.

## Исправления по результатам запуска

В InputMovementTests тест одиночного нажатия изначально упал. Простая поправка кадра не помогла. По исходникам установленного Input System установлено: defaultUpdateType возвращает Editor при отсутствии фокуса, поэтому синтетические события не попадали в игровой state. Тест временно задаёт IgnoreFocus и AllDeviceInputAlwaysGoesToGameView и восстанавливает настройки в finally. Исходные assertions удержания, одинакового снимка в кадре и второго нажатия сохранены. LocalInputSource и остальная боевая логика не менялись.

Команда создания preview в batch наткнулась на пустую Untitled-сцену: Additive в этом случае запрещён Unity. После проверки dirty-сцен batch использует Single; обычная редакторская команда остаётся Additive. Перезапись существующего имени запрещена, старые ресурсы сохраняются.
