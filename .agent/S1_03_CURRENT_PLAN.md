## Decision Log


Decision: использовать отдельную Stage1ArenaPreview.unity. Rationale: не заменять существующие сцены и не нарушать старые Foundation-проверки. Date/Author: 2026-11-14, роль 2.

Decision: HUD получает IPlayerCombatSource, а prefab остаются неизменными. Rationale: контракт v0.1 уже достаточен; не переписывать боевую часть. Date/Author: 2026-11-14, роль 2.

Decision: изолировать фокус редактора в GamepadPressIsOnePulseAndRepeatedReadsShareSnapshot через временные IgnoreFocus и AllDeviceInputAlwaysGoesToGameView с восстановлением в finally. Rationale: InputManager.defaultUpdateType в установленном Input System 1.20.1 выбирает Editor update без фокуса; тестовые события не доходили в игровой state. Все исходные проверки сохранены, рабочий LocalInputSource не менялся. Изолированный и полный прогоны после исправления успешны. Date/Author: 2026-11-14, роль 2.

Decision: при batch-создании preview использовать Single после проверки несохранённых изменений; в обычном редакторе сохраняется Additive. Rationale: Unity запрещает Additive рядом с исходной безымянной сценой batch-запуска. Date/Author: 2026-11-14, роль 2.
