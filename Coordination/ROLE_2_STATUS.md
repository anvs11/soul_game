## Причина и исправление границ

В реальной CombatSandbox физический размер четырёх BoxCollider2D был .0001×.0001 при видимых больших спрайтах. Collider добавлялся до присвоения спрайта. В CombatSandbox и Stage1ArenaPreview через Unity заданы явные size=1×1 и scale.z=1; сохранены GUID сцен. Исправлены оба генератора стен. Добавлен ArenaCameraFit: вся текущая арена помещается в ортографическую камеру при разном aspect. Стены блокируют героя, врагов, пули и отбрасывание; обхода телепортацией по границе не добавлено.

Новый regression-тест запускает Bootstrap, проверяет collider именно сохранённой сцены, движение и отбрасывание в четыре края и врага, преследующего тестовую цель за стеной. Поэтому прежний пробел тестирования искусственной стенки закрыт.

Единственный кандидат для создания основы: Unity 6000.3.28f1 (6.3 LTS).
Реальность выпуска проверена по официальной странице Unity:
https://unity.com/releases/editor/whats-new/6000.3.28f1
Это не результат локального запуска и не окончательная фиксация совместимости.
Конкретные версии Input System, Unity UI и Test Framework не назначены:
их выбирает Package Manager, после успешной сборки сохраняются фактические manifest.json и packages-lock.json.
Установленный редактор и SDK вне проекта не искались и не запускались.

## Проверки

Непосредственный осмотр корня, поиск основы внутри него и чтение правил выполнены.
Выполнены статические проверки четырёх JSON .asmdef, ссылок и платформ сборок, синтаксиса PowerShell и правил Git. Реальный запуск Install.ps1 без Game/ завершился ожидаемым кодом 1 с Game/ is absent: папка не создана, непосредственное содержимое корня не изменилось. Проверены новые рабочие пути документов и наличие двенадцати разделов ExecPlan. Доказательства записаны в .agent/S1_01_FOUNDATION_PLAN.md. Перенос в настоящий проект и компиляция C# не проверены.
Unity-компиляция, импорт и генерация .meta, применение Force Text/Visible Meta Files,
установка пакетов, EditMode/PlayMode, сборка Windows и проверка Android не выполнены.
Ноль тестов не считается успешной проверкой.

## Остаётся до передачи

1. Человек создаёт Game/ через Hub по .agent/S1_01_SETUP.md.
2. Устанавливает пакеты, включает новый Input System, закрывает редактор.
3. Выполняет Install.ps1 сначала без -Apply, затем с -Apply; повторно открывает Game/.
4. Применяет настройки через Game/Setup и проверяет отчёт фактических версий.
5. Собирает и запускает проверочную пустую сцену; сохраняет версии и доказательство в Game/Docs/TECH_BASELINE.md.
6. В следующем шаге роли создаём Bootstrap, Home, CombatSandbox и пустой цикл; проверяем десять повторов.
7. Оба участника получают одну основу с .meta и открывают её. Только после этого принимается S1-01.

Модель Android-телефона не предоставлена; нужна до мобильной приёмки.
Следующий результат участника 1 — S1-02 (ввод, движение, здоровье, герой), после принятия общей основы.
