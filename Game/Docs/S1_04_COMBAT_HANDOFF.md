## Поведение и настройки

Герой: скорость 5, HP 100, броня 30, защита после принятого урона .5 с, выносливость 100. Пистолет: магазин 8, запас 16, урон 10, интервал .25 с, перезарядка 1 с, скорость пули 25, время жизни 2, радиус .08. Радиус автоприцела пистолета = скорость × время жизни = 50; ножа — 1.2. Стрельба только по удержанию атаки, выбор цели не нажимает атаку сам.

Нож: урон 15, радиус 1.2, сектор 100°, интервал .45 с, цена 20. Выносливость возвращается 25/с только с пистолетом, включая пустой 0/0. Смена слота не пересоздаёт ресурс и отменяет reload без списания. Начальное направление вниз, до первой цели направление следует последнему движению. После выбора цели сохраняется последнее направление на неё; при потере цели дальнейшее движение его не затирает, пока новая цель не выбрана.

SandboxEnemy.prefab: HP 30, броня 0, собственная защита после попадания 0, скорость 2.5, контактный урон 10 с интервалом попыток 1 с. Игрок сохраняет свою защиту .5 с. Enemy-префаб уже содержит нужную конфигурацию DamageReceiver: добавление одного SandboxEnemy на произвольный объект не заменяет настройку 30/0/0. Для программного создания сначала на неактивном объекте Configure(30, 0, 0) у ещё не использованного DamageReceiver, затем включение. Enemy реализует IDefeatable; смерть останавливает физику и collider, снимает врага с registry до Died, событие один раз за экземпляр. Деактивация/выгрузка только снимает регистрацию. Перезапуск требует новых экземпляров, включение мёртвого его не оживляет.

Реестр локален для сцены, без singleton и поиска объектов. Враг регистрируется через явные ссылки либо Initialize. Selector перебирает зарегистрированных врагов при команде (для трёх целей прототипа), выбирает ближайшего живого видимого в радиусе; равенство расстояний разрешает меньший ActorId. Подписка Removed немедленно сбрасывает текущую цель. Реестр должен жить весь срок арены; не выключать его отдельно от арены, иначе живых врагов требуется снова Initialize/включить для регистрации.

## Слои и физика

В текущих ProjectSettings ещё нет World/Player/Enemy. CombatDev_A использует Default без изменения общих настроек; фракции Player и Enemy записаны на соответствующих prefab. Временный стенд не является окончательной матрицей столкновений.

Для общей интеграции владелец ProjectSettings добавляет World, Player, Enemy, PlayerProjectile, EnemyProjectile, Pickup в согласованные свободные индексы. Стенам назначить World, герою Player, врагам Enemy. Разрешить физические столкновения Player↔World, Enemy↔World, Player↔Enemy; Enemy↔Enemy можно оставить включёнными для простого разделения толпы. Collider не trigger, тела — Rigidbody2D с gravityScale=0 и замороженным вращением. Контактный урон работает только при физических collision-событиях.

Projectile.prefab не имеет collider/Rigidbody: единственный путь попадания — CircleCast по пройденному отрезку. WeaponController.hitMask должен включать World/Player/Enemy (владелец и союзники отбрасываются по ActorIdentity). MeleeAttack использует ту же маску для целей и препятствий. AutoAimSelector.obstructionMask для общей арены назначить World. В диагностике All Layers безопасен: видимость игнорирует collider с ActorIdentity, а collider без него считает геометрией мира. Каждый персонаж должен иметь ActorIdentity на корне выше collider. Trigger-зоны не блокируют выбор. Геометрия, не включённая в obstructionMask, не перекрывает автоприцел.

## CombatDev_A и приёмка

Сцена подготовлена: один герой, локальный реестр, три экземпляра Enemy-префаба с явными ссылками, четыре граничные стены, внутреннее препятствие и сохранённая временная статическая цель из предыдущих проверок. Последняя не входит в registry и не является одним из трёх врагов. Ближайший враг справа изначально закрыт внутренней стеной, два слева видимы; преследователь может упереться в препятствие, поскольку поиска пути нет. Для точного осмотра стартового выбора включить Pause в Editor до первого шага и двигаться по кадрам. В Game view диагностическая строка показывает ActorId цели и AimDirection.

Открыть Game/, дождаться импорта/компиляции, открыть Assets/_Game/Scenes/CombatDev_A.unity и Play. Проверить выбор видимого вместо скрытого, убить текущую цель: выбранная ссылка должна исчезнуть сразу, следующая атака выберет другую. Стрелять Space, менять слот Q, двигаться WASD/стрелками. Три принятые пули убивают 30 HP; два принятых удара ножа тоже. При контакте броня героя уменьшается не чаще чем раз в секунду; смерть героя останавливает преследователей. Остановить Play и повторить: снова три новых врага, один герой, полный стартовый ресурс. Это проверка боевой заготовки, без общей победы/результата/Home.

Запустить Test Runner: ожидаются 21 EditMode и 15 PlayMode. Четыре новых AutoAimEnemyTests проверяют ближайшего за стеной/следующего видимого, дальность, немедленный сброс погибшего, однократный Died и выключение без убийства, tie-break по ActorId, очистку registry, контактный лимит и остановку на смерти героя, сохранение направления после первой цели. Записать фактические counts и XML в новую Game/TestResults/<runId>/.
