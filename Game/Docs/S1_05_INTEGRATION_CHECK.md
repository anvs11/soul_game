# S1-05 — основной цикл с боем

14 ноября 2026, локальная ветка feat/stage1-flow-ui. В основной CombatSandbox вместо EmptyArenaScreen подключён ArenaController, один Player.prefab, три SandboxEnemy.prefab, локальный TargetRegistry, реальный HUD и выход справа внизу (8, -4). Исходные prefab У1 и контракт v0.1 сохранены.

## Поведение

Из Bootstrap → Home → бой. Space атакует, Q меняет оружие, WASD перемещает. Выход красный до трёх уникальных смертей, после зачистки зелёный. E действует в радиусе 1,5 единицы от выхода; раннее или удалённое взаимодействие не завершает попытку. Мёртвый герой не может выйти. RunCoordinator разрешает один исход в конце кадра, Defeat приоритетнее Victory. Выключение/выгрузка не создаёт события убийства. Бой блокируется при уходе со сцены, подписки снимаются.

Результат показывается в Home как отдельный экран «Победа»/«Поражение». Кнопка «В убежище» переводит на обычный стартовый экран той же сцены. Следующий старт создаёт свежие объекты и ресурсы. Награды не начисляются.
