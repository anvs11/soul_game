## Validation and Acceptance

Новые EditMode проверки маршрута, неверного набора/индекса/позднего запроса, исхода в том же кадре и невалидных Id. PlayMode проходит из Bootstrap через настоящую третью кнопку, подтверждает5 разных экземпляров, ожидаемые Id, реальное число врагов, отсутствие промежуточного результата и перенос ресурсов, паузу/повтор/Defeat. Отдельная проверка создаёт каждый prefab, сравнивает все клетки с физикой World и проверяет BFS ко всем входам/выходам/спавнам. Боссовый collider и кандидаты призыва проверяются на свободной площадке. Сохранить прежние Foundation assertions. Ручной просмотр — Bootstrap, StreetRun, обычный бой, E у зелёной двери, итог после босса.
