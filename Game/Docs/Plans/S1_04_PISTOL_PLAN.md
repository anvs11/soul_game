## Purpose / Big Picture


В CombatDev_A герой стреляет Space по последнему направлению движения (начальное вниз). Временная цель принимает урон; стены останавливают пулю. Q временно убирает пистолет, повторный Q возвращает; второго оружия пока нет. Общая CombatSandbox не меняется.

## Surprises & Discoveries


Слои Player/World/Enemy пока отсутствуют. В отдельной сцене используем Default, фракция и владелец исключают собственные попадания. Для стен достаточно collider без ActorIdentity. Основная арена остаётся пустой.

## Decision Log


Решение 2026-11-14: один путь попадания — CircleCast по пройденному за FixedUpdate отрезку; у пули нет collider, callbacks попадания отсутствуют. Переиспользуемый список результатов исключает ограничение фиксированного буфера; выбирается ближайшее допустимое препятствие. ObjectPool хранит объекты, отдельный HashSet ограничивает активные экземпляры. Состояние магазина и таймеров принадлежит WeaponRuntimeState, определение ScriptableObject неизменяемо со стороны runtime. Q выбирает отсутствие пистолета, не изображает готовый нож.

## Interfaces and Dependencies


IProjectileSpawner.TrySpawn(in ProjectileSpawnRequest) возвращает true только при созданном активном снаряде. Request несёт позицию, направление, скорость, срок жизни, радиус, маску, владельца, фракцию и DamagePacket. WeaponRuntimeState не зависит от сцен и Time, но использует Vector2 в запросе. Projectile использует Physics2D.CircleCast, пул — UnityEngine.Pool.ObjectPool. Новых пакетов нет.
