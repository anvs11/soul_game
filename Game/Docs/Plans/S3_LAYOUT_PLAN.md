## Validation and Acceptance

Тесты проверяют копирование входов и недоступность изменяемых массивов наружу, дубликаты Id/неверные размеры/координаты, формат успеха/отказа и безопасные заглушки. Проверка примера должна показать6 модулей и отсутствие успешного Layout от неготового Generate. Подсчёт Test-атрибутов не считать Runner Passed. Если компиляция недоступна, указать NOT RUN и передать У2 точные действия, не объявлять компиляционную готовность.

## Idempotence and Recovery

Не менять ранее принятые ресурсы, контракты боя, подписки и сцены. Сохранять старые отчёты и локальные изменения. Для новых результатов выбирать уникальные каталоги. Ошибки формы данных не скрывать успешным fallback. Ошибки компиляции исправлять минимально, не меняя согласованный публичный API без дополнения к передаче.
