## Surprises & Discoveries

S3-03A: первый этап теперь возвращает успешный кандидат, но не проверяет геометрию. Сохранённая заглушка LayoutValidator отвергает даже такой кандидат, поэтому runtime не должен стартовать только по IsSuccess. Число уникальных схем не обязано равняться числу seed: Python reference для64 seed дала54 схемы; это не результат исполнения C#.

У2 уже принял S2-08 в main и сообщает Windows42/84; XML здесь отсутствуют. Unity6000.3.28f1 закреплена в ProjectVersion. UnityLockfile присутствует; не удалять и не запускать второй Editor. Пользователь разрешил Game/, но не предоставил исполняемый файл Editor/компилятора; command -v dotnet/csc/mcs не нашёл доступной команды. Это не доказывает отсутствие установленного Unity на машине.

## Decision Log

Решение S3-03A, 16 ноября, У1: generatorVersion=1 использует локальный uint32 SplitMix32 (Weyl increment 0x9E3779B9 и avalanche 0x85EBCA6B/0xC2B2AE35), seed через unchecked(uint), ограниченный индекс через rejection sampling. Combat/Boss сортируются StringComparer.Ordinal, выбор с возвращением:4 Combat и1 Boss. Версии генератора/контента пока поддерживают только1; прочие положительные версии дают Failure. ContentVersion — согласованная метка снимка, не автоматически вычисленный hash каталога. Проверку проходимости/попытки/fallback не реализовывать до S3-03B; успех Generate пока означает кандидат, LayoutValidator остаётся блокирующей заглушкой.

Решение16 ноября, У1: новые чистые типы Game.Generation размещать в Scripts/Generation, Unity-адаптеры и контроллеры остаются у У2. Старую предложенную Generate(StageDefinition) из EXCECPLAN уточняет контракт S3_01_LAYOUT_CONTRACT; обе сигнатуры параллельно не реализуются.

Решение16 ноября, У1: конструкторы проверяют форму/границы и защищают коллекции копиями; семантику пяти сегментов и достижимость проверяет будущий LayoutValidator. Пока Generate/Validate возвращают явный неуспех, не бросают NotImplementedException и не притворяются успешной генерацией. Невалидные null/аргументы публичного API — ArgumentException/ArgumentNullException.

Не менять ранее принятые ресурсы, контракты боя, подписки и сцены. Сохранять старые отчёты и локальные изменения. Для новых результатов выбирать уникальные каталоги.
