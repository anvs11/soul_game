## Purpose / Big Picture


В CombatDev_A герой автоматически направляет ручную атаку в ближайшего видимого живого врага. Три экземпляра одного простого преследователя приближаются и наносят контактный урон. Смерть исключает врага из выбора и вызывает Died один раз. Основная CombatSandbox остаётся задачей участника 2.

## Surprises & Discoveries


DamageReceiver пока задаёт всем актёрам 100/30 и защиту .5 с. Добавляем сериализуемые начальные значения, сохраняя значения игрока; враг получает 30/0 и нулевую защиту, чтобы три пули по 10 принимались без искусственной неуязвимости. Слои World/Player/Enemy отсутствуют: временная сцена использует Default и фракции, видимость учитывает только collider без ActorIdentity как геометрию мира.

## Decision Log


Решение 2026-11-14: реестр — отдельный компонент сцены с явными ссылками, без static singleton и FindObjects. Враг регистрируется при включении после привязки, снимается при смерти/выключении/уничтожении. Selector получает registry сериализованно, перебирает трёх врагов без LINQ; Physics2D.Linecast с переиспользуемым списком блокирует кандидатов за геометрией мира, равная дистанция разрешается по ActorId. Для малого прототипа выбор выполняется на команду, без поиска объектов сцены; оптимизация частоты для больших волн не заявляется.

Контроллер сохраняет направление последней выбранной цели даже при её потере; до первой цели следует движению, начальное направление вниз. Пистолет использует радиус из WeaponDefinition, нож — MeleeAttack.Radius. Контакт только через OnCollisionEnter2D/Stay2D: общий таймер на врага 1 с исключает удвоение от collider. Скорость 2.5 против скорости героя 5, движение Rigidbody2D в FixedUpdate, поиска пути нет.

## Validation and Acceptance


Ближайший враг за стеной не выбирается; следующая видимая цель выбирается. Убийство выбранного врага немедленно снимает его и переключает выбор; выключение не вызывает Died. В пределах дальности выбирается ближайший живой, за пределами — сохраняется направление. После первой цели движение не затирает последнее направление при потере цели. Три пули убивают врага 30 HP; два удара ножом тоже. Контакт наносит 10 не чаще 1 с, даже при нескольких collider. Отключение сцены оставляет пустой registry, повторный запуск создаёт новых врагов. Смерть героя останавливает преследование и атаки врага. Ручной прогон и тесты без Unity не считать выполненными.

## Idempotence and Recovery


Не удалять старые ресурсы, не заменять общие сцены и настройки, не сбрасывать Git. При конфликте имён сохранить оригинал. Выключение/выгрузка — отписка, не смерть; повторное включение мёртвого врага не регистрирует его заново. Данные состояния не восстанавливаются из prefab до новой инстанциации.
