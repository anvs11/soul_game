# S5-05. Профиль и контрольные точки City

[Интерфейс репозитория](../Assets/_Game/Scripts/Progression/ISaveRepository.cs) · [JSON-репозиторий](../Assets/_Game/Scripts/Progression/JsonSaveRepository.cs) · [EditMode-тесты](../Assets/_Game/Tests/EditMode/ProgressionSaveTests.cs)

## Подключение У2

Создайте один `CityProgressionSession(() => Time.timeAsDouble, new JsonSaveRepository(profileDirectory))` на открытый профиль. В разработке передайте абсолютный путь к `Game/LocalState`. В тестах используйте `Game/TestResults/Saves/<testRunId>`. В сборке каталог предоставляет приложение. Для явного открытия отдельного профиля создайте репозиторий с другим каталогом и замените сессию в Home.

- При открытии профиля активная попытка после прерывания становится `Abandoned`, а Home получает последний подтверждённый баланс и `LastRun`. После открытия на диске нет активной попытки. Временные монеты, добыча и модификации живут только в памяти. Смерть и явный выход обрабатываются через `FinishRun` с соответствующим исходом.
- Вызывайте `StartRun` перед запуском боевой сцены. Для создания героя используйте `Run.StartingWeaponId` из результата принятой команды. Привяжите этот ID к каталогу стартового оружия в адаптере У2. Базовый ID — `pistol`. Покупка в Home открывает и выбирает альтернативу для следующей попытки. По умолчанию `unlock-city-pistol` открывает `pistol-city` за 20 кристаллов. Другой ID и цену передайте через `ProgressionHomeOffer` в конструктор сессии. Цену будущего возрождения фиксирует `ProfileData.FutureRevivalPriceCrystals = 500`.
- `ClearCheckpoint` подтверждает кристаллы комнаты и ключ `RunId/checkpointIndex` одной ревизией. `Replayed` возвращает исход сохранённой операции и текущий снимок. Ключ с другой комнатой или индексом получает `Conflict`. Кристаллы с земли зачищенной комнаты входят в начисление.
- При `RetryableFailure / SaveFailed` покажите повтор записи и используйте прежний `ActionId` с прежними параметрами. Зачистка оставляет ожидающие кристаллы до успешного повтора. При ошибке на старте или переходе не загружайте следующую сцену. При ошибке завершения оставьте экран результата доступным для повтора команды. Если процесс завершился, при следующем запуске сессия сохранит последнюю подтверждённую ревизию и вернёт игрока в Home.
- `RecoveredFromBackup` означает, что загружена последняя доступная исправная ревизия. `IncompatibleSchema` блокирует запись и требует явного открытия отдельного профиля. `Unavailable` означает повреждение обоих слотов или недоступность записи либо чтения при открытии. При недоступности повторяйте операцию после устранения причины.
- Регион `city` засчитывается после победы на 1-5. Победа в игровом срезе 1-1 завершает попытку и сохраняет начисления этой попытки.

## Формат и восстановление

JSON схемы 1 хранит `schemaVersion`, `revision`, подтверждённые кристаллы, открытия, выбранное оружие, завершённые регионы, активную попытку и журналы зачислений, завершений и покупок. Контрольная сумма SHA-256 проверяет прочитанные поля профиля. Новая ревизия проходит запись и повторное чтение в `profile.pending.json` перед публикацией. При доступном `File.Replace` прежняя исправная ревизия переходит в резерв. При отсутствии атомарной замены запись идёт в другой слот A/B, а текущий исправный слот остаётся доступен. Загрузка выбирает последнюю валидную ревизию. Подготовленный файл не участвует в загрузке.

Один открытый игровой сеанс владеет активной попыткой профиля. Блокировка файлов и сверка ожидаемой ревизии защищают от конкурирующих записей. Сессия перечитывает профиль при конфликте ревизий, после чего тот же ключ можно повторить. Неизвестная будущая схема в любом опубликованном слоте блокирует запись в этот каталог.

## Как проверить

В Unity **6000.3.28f1** откройте `Game`, затем **Window → General → Test Runner → EditMode** и запустите `Game.Tests.ProgressionSaveTests`. Каждый сценарий создаёт отдельную папку в `Game/TestResults/Saves`. Для прогона из корня репозитория закройте интерактивный редактор и используйте путь к установленному Unity.

```sh
mkdir -p Game/TestResults/S5-05
"/path/to/Unity" -batchmode -nographics -projectPath "$PWD/Game" \
  -runTests -testPlatform EditMode -testFilter Game.Tests.ProgressionSaveTests \
  -testResults "$PWD/Game/TestResults/S5-05/EditMode.xml" \
  -logFile "$PWD/Game/TestResults/S5-05/EditMode.log"
```

Сценарии покрывают оба режима записи, повреждение, готовый и прерванный подготовленный файл, несовместимую схему, повтор после ошибки, конкурирующие записи, смерть и выход, открытие после прерывания, покупку и выбор оружия. Фактический прогон Unity остаётся открытым.
