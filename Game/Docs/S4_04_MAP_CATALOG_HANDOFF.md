## Каталог для У1

`Game/Docs/Exports/S4_FIXED_MAP_V2.json` — новый машинный экспорт. Типизированный источник `Game.StreetMap.StreetMapCatalog.Create()` возвращает точный S4-01 EncounterMap, MapId=fixed_street_1_1, MapVersion=2, GeometryVersion=1, cellSize=1. Позиции точек локальны от центра комнаты. RoomId/PointId/AllowedEnemyTypeIds записаны явно. Для ordinary комнат бюджет6–8, MaxCost8, MaxWaves2, по8 кандидатных точек и отдельный hero_entry. Это целевой каталог для будущего S4-03; фиксированный диагностический runtime использует отдельные исходные планы меньшего бюджета. Смешивать его с новым бюджетом6–8 нельзя.

В elite3 точки с допустимыми тремя elite-Id, бюджет3/3/9/1 с12 резервными summon слотами. Проверена свобода круга радиуса1 от настоящих World-collider, но `elitePrefabsCertified=false`: реальных prefab всех новых видов ещё нет, их размеры/телепорт/таран/площадь предупреждений/дочерние точки не аттестованы. Этот экспорт пригоден У1 для структурного планирования/будущей1000 seed проверки; он не доказывает готовность исполнения элиты. После появления этих prefab и укрытий нужен новый физический аудит/версия экспорта. Здесь нет размещений мини-слизней, только ранее согласованный конечный бюджет слотов.

JSON rooms содержит centerX/Y,width/height,isElite,minEnemies/maxEnemies/maxCost/maxWaves/maxSummons, points с pointId/x/y/clearanceRadius/isHeroEntry/allowedEnemyTypeIds. corridors — world rect x/y/width/height. Конструкторы S4-01 могут восстановить эти неизменяемые типы без Unity сцены. География фиксирована, randomness будущего planner затрагивает только состав/позиции. GeneratorVersion/ContentVersion назначаются при S4-03; MapVersion2 должен участвовать в воспроизводимости. JSON включает32 точки всего: entry1, ordinary3×9, elite4.

`StreetMapCatalog.Reachable(.45f)` на настоящей геометрии выполняет BFS по клеткам с OverlapCircle и CircleCast до соседа, World-маска. Все5 комнат, все32 точки и конечная клетка выхода(85,24) достижимы,1920 клеток доступны. Clearance каждой точки проверен её собственным радиусом против реальных стен, не только по прямоугольным координатам. Тест импортированных Player/SandboxEnemy/JumpingEnemy/ShootingEnemy prefab проверяет реальную форму CircleCollider2D, offset и lossyScale: радиус каждого сейчас.4, следовательно геройский круг.45/ordinary clearance.6 их покрывает. Новые укрытия потребуют перепроверки; текущая геометрия ещё не содержит желаемых машин/шин/мусорных баков.
