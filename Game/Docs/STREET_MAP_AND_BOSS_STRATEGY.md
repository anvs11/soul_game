# Карта улицы и усиленные столкновения — уточнение пользователя

16 ноября2026. Принято из ручной обратной связи после S3-04A. Этот документ уточняет целевую игру и будущую задачу генератора. Реализация текущего S3-04B остаётся проверкой переходов на одной площадке каждого сегмента. Пользовательские референсы Soul Knight показывают несколько соединённых боевых прямоугольников в одной карте стадии.

## Структура стадий

1-1…1-5 — пять последовательных стадий улицы. Каждая целевая стадия содержит несколько боевых комнат/площадок, соединённых заранее заданными проходами. География карты известна и сохраняется от попытки к попытке. Игрок видит план маршрута, комнаты и соединения. Карта не раскрывает количество, типы и позиции противников. Комнаты зачищаются внутри стадии, переход в следующую стадию открывается после всей обязательной зачистки.

Межкомнатное движение на такой карте будет обычным перемещением через проходы. Портал нужен между завершёнными стадиями1-1→1-2 и далее. Он появляется у завершённого финального столкновения, рядом с героем/площадкой босса в безопасной достижимой точке. Внутри одной стадии отдельный портал на каждую комнату не требуется. Финальная развязка1-5 уточняется вместе с завершением уровня.

Число врагов, позиции, типы и соотношение типов меняются между попытками в рамках конечного бюджета каждой комнаты и допустимых точек. Усиленные встречи следуют описанной ниже прогрессии. Для проверки seed должен воспроизводить столкновения при тех же версиях данных. Обычный новый старт получает новый seed при реализации этой функции. Случайная геометрия и перестановка боевых комнат исключены новым направлением проекта.

## Прогрессия столкновений

На1-1 и1-2 преимущественно базовые зомби. Одна комната каждой такой стадии содержит усиленную встречу с2–3 мини-боссами со своими особенностями. После победы задумана добыча и возможность продолжить маршрут.

На1-3 есть комната с сильным боссом, несколько слабее финального. Эта встреча должна требовать освоения механик уклонения и ресурсов.

На1-4 есть площадка с несколькими мини-боссами. На1-5 находится самый сложный финальный босс, ориентир — нынешний большой полицейский. Аналогичный подход применяется к последующим уровням2 и3. Типы мини-боссов, их конкретные атаки, HP, бюджеты и награды требуют отдельного проектирования и ручной оценки.

## Влияние на работу У1 и У2

Предыдущие START_STAGE_3_ROLE_* описывали выбор последовательности room ModuleId по seed. Это ранний прототип. После этого уточнения будущая интеграция S3-06 должна сначала зафиксировать новый контракт с У1. Генератор выбирает Encounter-планы для узлов постоянной карты. Данные геометрии, клеточный валидатор, проверка достижимости и конечный fallback сохраняют применение. Подменять новую модель случайной перестановкой street_a/b/c нельзя.

Текущий StreetRoute a,b,c,a,boss служит тестовой цепочкой пяти переходов. Шесть модулей и JSON из S3-04A остаются техническими заготовками. Следующая согласованная задача — одна целевая фиксированная карта стадии1-1 с несколькими комнатами и блокировкой проходов на время боя, затем контракт изменяемых составов столкновений У1. Масштабировать такую карту на все5 стадий нужно после проверки одной.

Готовые типы мини-боссов, система лута и полноценная карта комнат этим документом не объявляются реализованными. Для нынешнего S3-04B пользователь попросил увеличить обнаружение и показывать ближний портал после зачистки текущей тестовой площадки. Именно это применяется сейчас. Полный MVP и платформенная приёмка остаются отдельными проверяемыми результатами.
