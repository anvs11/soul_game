## Как открыть

В Unity **6000.3.28f1** откройте `Game/Assets/_Game/Scenes/Bootstrap.unity`, нажмите Play и выберите **Карта города → Проверка ранчо · 5-1**. Для воспроизведения можно указать seed **41** в поле seed на Home. Пустое поле в режиме проверки использует 0. Диагностический маршрут работает без записи прогресса в профиль CITY. Обычный запуск с проверкой доступа и сохранением победы относится к S9-03.

## Маршрут

- Безопасный вход начинается в (0; 0). Двор и загон содержат по одной волне из 4–6 обычных зомби. Seed определяет число, порядок типов и точки появления. Одинаковый seed даёт тот же набор `SpawnId`, типов и точек. У каждого боя есть свой проход вперёд, который закрыт до зачистки. Входные ворота закрываются, когда коллайдер героя полностью внутри.
- Капкан находится в боковом проходе загона в (48; 5,6). Прямой проход вдоль y = 0 остаётся свободным. После зачистки загона на дороге к амбару появляется один запас из восьми патронов в (64; 0,65), подобрать его можно через E.
- В амбаре появляется один `ranch_deer` из prefab У1. Из точки появления (84; 0) проверены восемь единиц прямой полосы разгона и оба боковых пути уклонения. Выход в (89; 4,5) открывается после всех трёх встреч. Подойдите к нему и нажмите E для возврата в убежище.
- Мини-карта использует те же четыре границы комнат и три коридора, что физическая карта. Метка героя обновляется по его координатам, посещённая комната меняет цвет. Точки капкана и врагов отсутствуют на мини-карте.

## Точки подключения для S9-03

Геометрия, ключ сегмента `ranch/5-1` и план встреч находятся в [RanchLayout](../Assets/_Game/Scripts/StreetMap/RanchLayout.cs). [RanchStage.asset](../Assets/_Game/Resources/Data/Stages/RanchStage.asset) хранит ссылки на prefab и размер запаса патронов. [RanchMapScene](../Assets/_Game/Scripts/StreetMap/RanchMapScene.cs) строит коллайдеры и ворота и передаёт актёров в общий RoomController. Карта использует существующую сцену Stage4StreetMap. При запуске ранчо её уличная геометрия отключается только в текущем экземпляре сцены.

В S9-03 используйте `yard`, `pen` и `barn` для индексов контрольных точек 0, 1 и 2. Условия открытия ворот и выхода в сохраняемой попытке должны учитывать успешное подтверждение контрольной точки. На S9-02 режим проверки открывает их по фактической зачистке.
