## Контракт для У2

- Регион `ranch`, сегмент `ranch/5-1`. Контрольные точки задаёт `RanchProgression.TryCheckpoint`. Двор `yard` получает индекс 0, загон `pen` — 1, амбар `barn` — 2.
- `CityProgressionSession.StartRanch(key, seed)` начинает отдельную попытку с RunId из ключа, проверяет завершение CITY и читает выбранное стартовое оружие. ID оружия берётся из `Snapshot.Run.StartingWeaponId`. Прохождение канализации или чертёж для доступа не нужны.
- Передайте `ConfirmEnemyDeath` до `ClearCheckpoint`. Используйте стабильные ключи вида `death/<SpawnId>` и `clear/ranch/5-1/<RoomId>`. Начисление и запись контрольной точки проходят одной ревизией. Смерть и выход сохраняют подтверждённые кристаллы. Неподтверждённая часть и монеты заканчиваются вместе с попыткой.
- После подтверждения амбара вызовите `FinishRun(key, Victory)`. Запись `ranch` появляется один раз. Повтор завершённой команды возвращает `Replayed` и текущий снимок. После ошибки записи повторите исходную команду с тем же ключом.
- Сохранения схемы 1 читаются по прежним полям. Список из 15 сегментов CITY используется как раньше. Ранчо имеет собственный маршрут из одного сегмента.

## Интеграция для У1

Из `Bootstrap.unity` откройте **Карта города → Ранчо · 5-1** на профиле с сохранённой победой CITY. При закрытом регионе обычная кнопка недоступна. **Проверка ранчо · 5-1** доступна отдельно и использует временный профиль в памяти. Для воспроизведения целевых PlayMode-сценариев можно установить seed 41.

Перед загрузкой сцены координатор получает принятый профильный старт. В сцене адаптер экипирует выбранный пистолет и связывает общий сервис с героем. При ошибке записи зачистки игрок остаётся на карте, ворота закрыты, а подтверждённый баланс сохраняет старое значение. Кнопка «Повторить сохранение» повторяет зачистку или возврат в Home. Победа появляется в профиле после сохранённого возврата через выход. В проверочном режиме основной профиль остаётся на прежней ревизии.
