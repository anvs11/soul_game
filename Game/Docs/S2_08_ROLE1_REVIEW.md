## Найденные дефекты и исправления

Если пул был отключён извне, Initialize/OnDisable либо обработка отсутствующего игрока снимали эту блокировку. Исправлено вызовом существующего ClearActive(), без изменения enabled. Политика очистки активных снарядов при смерти/disable/смене цели сохранена. Призывы и таймеры оружия не менялись.

Все исправления подготовлены по минимальному Game/Docs/Plans/S2_08_ROLE1_REVIEW_PLAN.md. До запуска новых регрессий нельзя объявлять их проверенными в Unity.

## Что установлено по коду

Ресурсы и переход: ArenaController перед CompleteArena передаёт функцию чтения настоящего CombatSnapshot; RunCoordinator разрешает pendingOutcome раньше pendingAdvance в LateUpdate, проверяет смерть поздним снимком, сохраняет PlayerTransfer и ActiveArena, не создаёт новый RunId на переходе. Boss-arena восстанавливает HP/броню/патроны/выносливость/выбранный слот, не выдаёт стартовые ресурсы заново. Таймеры локального оружия сбрасываются при переносе; это существующая политика, не объявляется переносом текущего reload-progress. Завершение/повтор очищают transfer. HUD.Bind получает реальный источник и немедленно читает его, Unbind/DetachCombat снимают подписки. Это статические выводы; кадровый порядок и UI требуют Runner и ручной проверки.

Исходы: FinishRun приоритет Defeat над Victory/Abandoned, pendingOutcome отменяет промежуточный переход. ArenaController требует три уникальных врага либо одного PoliceBoss, выход проверяет состояние/жизнь/зону, в boss encounter выход не завершает попытку — Victory по смерти босса. На уходе из InArena блокируются герой и AI, активные пулы сцены очищаются до выгрузки, timeScale возвращается1. Registry и Died не приравнивают выгрузку к убийству. Foundation-тесты не менялись в этом ревью.

Попадания/ресурсы: Projectile не имеет физического collider-path, попадание через один CircleCast по пройденному отрезку; перед применением DamagePacket active сбрасывается, в finally выполняется возврат. Владелец и союзная ненейтральная фракция исключаются. MeleeAttack дедуплицирует ActorId и receiver, JumpingEnemy не наносит урон в Dash и использует consumed для Land. Изменения не ослабляют расход ресурсов, TrySpawn-отказ или реальное попадание по стене. Barrel взрывается один раз, исключает другие barrel для цепи, дедуплицирует receiver, проверяет радиус/World, толчок/оглушение применяет после принятого несмертельного урона.

Реестр/миньоны: единый IEnemyTarget/TargetRegistry, отписки при disable/Initialize, немедленный сброс погибших в AutoAimSelector. ShieldMinion оборачивает SandboxEnemy движения с null-registry, регистрируется сам, отписывается и выключает движение при disable. Босс уничтожает принадлежащих ему миньонов и очищает пули при смерти/disable/недоступной цели/Initialize. Флаги summonedSecondStage/summonedThirdStage не сбрасываются при повторном включении/Initialize; стадия3 не повторяет призыв2 при прямом перескоке. Пороговые переходы монотонны; текущая атака использует зафиксированный attackLevel, новая — текущий Level. Эти правила не менялись.
