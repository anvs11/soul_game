# S4-06A — исполнение EncounterPlanner на карте 1-1

Ветка feat/stage4-map. Основа У1 — `843d2795af2e490dc0f7f6531b6eb85d53f8dcb1` с S4-03. Обычные комнаты на прежней географии выполняют 6–8 запланированных зомби. Для playback используются исходные melee/jumper/shooter prefab и один TargetRegistry. RoomController активирует только текущую волну, связывает SpawnId с экземпляром и задерживает следующую волну до смерти предыдущей плюс DelaySeconds. Занятая точка остаётся в ожидании. Исходные сцены, геометрия, prefab и мини-карта сохранены.

Из Bootstrap откройте Home, в верхнем поле введите целый seed или оставьте его пустым, затем нажмите «Играть 1-1». Неверный ввод даёт ошибку в Home. При пустом поле игра выбирает seed, показывает его в HUD и пишет лог `FIXED_STREET` с версиями, точками, волнами и диагностикой fallback. Повторите этот seed вручную для воспроизведения. «Тестовый маршрут 1-1» запускает прежний фиксированный сценарий. На стороне Home до загрузки проверяются ссылки на prefab, результат Generate и ValidateStage. Отказ оставляет игрока в Home. Имя и позиции комнат взяты из прежнего Unity-каталога. У мини-карты по-прежнему только данные географии и героя.

Использован `Game/Docs/Exports/S4_FIXED_MAP_V2.json`, MapVersion 2, GeometryVersion 1, G1/C1. SHA-256 e6e8e11ced9f1a1830104740b074599ac489d9a9d181c0ef7fea74e4f8485ff6. Windows Unity 6000.3.28f1. В `Game/TestResults/s406a-windows/` полный EditMode.xml содержит 136/136, включая проверку реального JSON на seed 0–999 с 0 отказов и 0 fallback. Отдельные EditMode-тесты проверяют валидный fallback с причиной и отказ повреждённым планам. PlayMode.xml содержит 107/107 и проверяет неверный ввод, пустое поле с выдачей нового seed, его повтор и запуск seed 42. SeededWaves.xml содержит 1/1 после расширения того же сценария. Проверены реальные типы и SpawnId, вторая волна combat_b, запертые двери между волнами и открытие после второй. Все три прогона завершились с exit 0, без отказов, пропусков и неопределённых результатов.

Финальная комната в запуске с seed использует три запланированные точки и три диагностических melee. Полный исходный план сохраняет выбранную пару элитных видов и резерв призывов. Реальные мини-боссы, их точки призыва и подборы ждут S4_05_COMBAT_RESOURCES_HANDOFF. S4-04C ждёт S4_05_MOVEMENT_STATUS_HANDOFF. Оба файла отсутствуют в опубликованной ветке feat/stage4-encounters на момент сверки. Ручной бой, Android, элита и новый физический экспорт её точек остаются открытыми. Передача для полноценного S4-07 должна включать их после S4-06B.
