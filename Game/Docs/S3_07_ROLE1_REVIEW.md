## P2 — портал не восстанавливается после неудачного размещения

Источник: `Game/Assets/_Game/Scripts/Sandbox/ArenaController.cs:116` и StreetExitPortal.TryOpen. OnEnemyDied вызывает TryOpen только при последней смерти, игнорируя false. В TryExit при закрытом портале сразу return; Update повторного размещения не делает. Если единственный поиск безопасной точки не удался из-за временной World-помехи, после её устранения зачистка остаётся без выхода.

**Воспроизведено на Mac Unity**, не только предположено по коду. Диагностический исходник — `Game/Docs/Reviews/S3_07_PORTAL_REPRO.cs.txt`; в snapshot он добавлен отдельным тестом Game.Tests.S307PortalReviewTests.FailedPortalPlacementIsNotRetriedAfterBlockerRemoval. Product-исходники/сцены не менялись.

1. Запустить Bootstrap/Home/StreetRun seed0, дождаться InArena первой площадки.
2. В тесте временно выключить симуляцию Rigidbody героя, включить queriesStartInColliders с последующим восстановлением. В позиции героя создать временный World BoxCollider2D4×4, SyncTransforms. Это детерминированная помеха, а не утверждение, что такая коробка уже есть в принятом модуле.
3. Убить3 обязательных врагов через настоящий DamageReceiver. RemainingEnemies=0, TryOpen не находит безопасной точки, IsOpen=false.
4. Удалить временную помеху, синхронизировать физику/вернуть симуляцию героя. Выполнить TryExit (аналог запроса Interact), дождаться кадра: портал всё ещё закрыт, попытка остаётся InArena.
5. Явный portal.TryOpen(hero) теперь возвращает true — точка доступна, но штатный контроллер сам не повторил поиск. XML содержит S307_REPRO с этим наблюдением. Cleanup восстанавливает глобальную настройку физики.

Для У2: предусмотреть ограниченный повтор после зачистки, например при Interact после проверок phase/alive/pause/remainingEnemies, либо управляемый таймер; не выполнять полный grid/Physics scan каждый кадр. Сохранять требования безопасной позиции и невозможность выйти до зачистки/после смерти. Добавить регрессию, ожидающую штатное открытие после удаления помехи; приложенная диагностическая проверка специально фиксирует старый дефект и не должна считаться проверкой исправления. На текущей штатной геометрии без временной помехи проблема не была встречена базовыми тестами. Исправление принадлежит Core/Street-владельцу У2; здесь не внесено.
