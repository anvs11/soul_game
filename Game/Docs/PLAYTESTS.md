# Stage 6 — протокол внешних тестов

23 ноября 2026. Цель — понять, насколько City 1-1 понятна человеку без объяснения из чата. Для общей приёмки нужно минимум пять попыток от трёх человек вне авторов. На начало проверки записей внешних игроков нет.

## Как провести попытку

1. Запустите Windows Player с отдельным профилем. Дайте игроку начать в убежище и выбрать улицу самостоятельно. При первом запуске оставьте поле seed пустым или зафиксируйте 5 для контрольного сценария. Для проверки торговцев можно использовать 0 или 7.
2. До начала не объясняйте боевую систему. Если игрок застрянет, отметьте точный момент, что он пробовал и какая подсказка помогла.
3. После завершения узнайте, почему, по мнению игрока, он победил или погиб. Спросите, менял ли он оружие, удалось ли найти лечение, был ли понятен способ вернуться и хочет ли он сыграть ещё раз.
4. Повторите только сценарии, в которых обнаружились одинаковые проблемы. Для Android отдельно запишите модель, разрешение, работу двух пальцев, сворачивание, звук и перекрытие UI пальцами.
