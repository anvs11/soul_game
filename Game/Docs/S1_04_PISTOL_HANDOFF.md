## Привязки

На Player.prefab добавлены ProjectilePool с Projectile.prefab и лимитом 128 активных пуль и WeaponController с Pistol.asset, ссылкой на pool и маской всех слоёв для отдельной сцены. Контроллер слушает motor.CommandSampled; Facade слушает изменения оружия и передаёт Magazine, MagazineCapacity, ReserveAmmo и IsReloading в существующий снимок. Данные ScriptableObject не хранят текущие патроны.

Пуля — визуальный sprite без Rigidbody и collider. Единственный источник попадания — CircleCast по отрезку за FixedUpdate с радиусом из определения, не физические callbacks. Из результатов выбирается ближайшее допустимое попадание, стены останавливают снаряд даже без DamageReceiver. Владелец и союзная ненейтральная фракция пропускаются. Collider целей должен быть не trigger; принадлежность ActorIdentity и DamageReceiver определяется в родителях collider. Пуля после первого попадания возвращается в пул, даже если урон отклонён защитой цели. Повреждение принявшей попадание цели не зависит от числа collider.

Пул создаёт отдельный корень в сцене владельца: пули не наследуют движение/масштаб героя. При возврате очищаются request (владелец, фракция, DamagePacket, направление, скорость, радиус), позиция, оставшееся время, список попаданий и callback. При выключении владельца активные пули возвращаются, при уничтожении очищаются хранилище и корень. Активный лимит отделён от количества хранящихся объектов. Маску и слои для общей интеграции согласовать с участником 2; Default подходит только для этой сцены.

## Проверка в Unity

Открыть Game/ в закреплённом редакторе, дождаться компиляции и открыть Assets/_Game/Scenes/CombatDev_A.unity. Дать фокус Game view и удерживать Space: начальное направление вниз ведёт к красной временной цели. Движение задаёт последнее направление выстрела; автоприцела пока нет. Цель имеет 100 здоровья и 30 брони, защиту .5 с и поэтому принимает не каждый выстрел с интервалом .25 с. Её здоровье видно в диагностике. Новая жизнь цели — перезапуск Play.

Отпустить Space после восьмого выстрела: сразу 0/16, на следующем обновлении начинается автоматическая перезарядка, после полной секунды 8/8. При удержании Space после завершения reload может сразу уйти следующий патрон — это ожидаемо. Всего доступны 24 стартовых выстрела, затем 0/0 без бесконечной перезарядки. Q убирает пистолет, повторный Q возвращает его. Ножа пока нет: это только проверка отмены reload. Q в середине перезарядки оставляет магазин 0 и запас 16, при возврате нужна новая полная секунда. Смерть и блокировка управления запрещают стрельбу; возврат из блокировки не восстанавливает патроны. Тестовая кнопка Esc регистрирует запрос, реальная пауза подключается позже владельцем UI.

Навести выстрелы движением на стены и внутреннее препятствие: пуля исчезает перед ними. В Test Runner выполнить EditMode (ожидается 17) и PlayMode (ожидается 9), сохранить XML в новую Game/TestResults/<runId>/. Четыре новых EditMode-теста проверяют 0/16→8/8, отказ спавнера без списания и cooldown, отмену reload и все 24 патрона с независимостью runtime-состояний. Новый PlayMode-тест проверяет быструю пулю перед стеной, лимит пула, повторное использование, попадание в цель с двумя collider и истечение срока жизни.
