## API и lifecycle

PoliceBoss.Configure(PoliceBossDefinition,ProjectilePool,GameObject shieldMinionPrefab,LayerMask world) до первой активации. На свежем объекте DamageReceiver настраивается отдельно Health/0/0, ActorIdentity Enemy, Rigidbody2D Continuous. Initialize(TargetRegistry,Transform) связывает существующие registry/цель, очищает прежние атаки/пули/призыв, сбрасывает подготовку, здоровье не восстанавливает. IEnemyTarget, IsDead, ActorId, Died, Level, PhaseTransitions, Phase, ShotsFired, LivingMinions, SpinDegrees доступны для HUD/проверок.

ShieldMinion.Initialize(TargetRegistry,Transform) вызывается перед активацией сохранённого inactive prefab. Wrapper регистрирует единственную IEnemyTarget, а внутренний SandboxEnemy.Initialize(null,player) ведёт принятое преследование/удар без второй регистрации. После.8с включается движение. Смерть снимает wrapper с registry и заканчивает жизнь. Прежний ближний удар.2/.06/.3 сохранён.

Смерть босса прекращает подготовку/движение/огонь, Died один, очищаются собственные пули и миньоны. Disable/смена/недоступность цели также очищают принадлежащие объекты, unload не вызывает Died. Призванные root-объекты помещаются в сцену босса. Повторное включение погибшего сохраняет Dead, живой начинает новую подготовку с сохранённым HP/Level. Собственные контакты с героем игнорируются, контролируемый толчок идёт через BeginKnockback.

Основные сцены/Core не менялись. ArenaController ещё не принимает PoliceBoss/ShieldMinion в switch и не задаёт боссовый маршрут. В S2-07 босс — единственная обязательная цель завершения боссовой арены, его миньоны принадлежат боссу и очищаются при смерти, не добавлять их в постоянный счётчик обязательной зачистки. Подключать через единственный TargetRegistry. Контракт CombatContracts v0.1 сохранён.
